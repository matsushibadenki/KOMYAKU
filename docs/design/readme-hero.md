## Purpose

The README hero communicates KOMYAKU before the detailed explanation begins. A manuscript becomes a branching Version Graph and passes through prose, mathematics, diagrams, tables, images, code, and AI conversation. The visual emphasizes document lineage, long-term preservation, and structured content without presenting an unfinished application UI as a finished product.

The restrained Japanese editorial style uses paper, ink, indigo, vermilion, and moss tones. No words or logos are embedded in the bitmap, so the image remains language-independent and does not duplicate accessible README text.
